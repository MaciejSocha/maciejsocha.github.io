ParametrizedLocator

Biblioteka Java do parametryzowania lokatorów w Page Objectach Selenium.

Problem

Lokator w Page Objecie to zwykły napis. Gdy kilka elementów różni się tylko etykietą, językiem interfejsu albo identyfikatorem wiersza, zostają dwie drogi: kopiowanie lokatorów albo pisanie metod pomocniczych, które składają XPath z kawałków tekstu. Obie szybko robią bałagan.

Jak to działa

  • Lokator definiujesz adnotacją @FindByParameterized, a w jego treści umieszczasz placeholdery w formacie {wec:nazwa.parametru}.
  • Wartości dostarcza implementacja IParameterProvider. Domyślna, DefaultParameterProvider, jest bezpieczna wątkowo, więc nadaje się do testów uruchamianych równolegle.
  • Biblioteka działa z PageFactory. W jednej klasie możesz łączyć lokatory parametryzowane ze zwykłym @FindBy.
  • Własnego providera przekazujesz jako wartość adnotacji.
  • Stronę możesz zbudować na WebDriver albo na WebElement.

Instalacja

<dependency>
  <groupId>click.webelement</groupId>
  <artifactId>parameterized-findby</artifactId>
  <version>1.0.0</version>
</dependency>

Przykład

Test aplikacji wielojęzycznej: ten sam przycisk, inna etykieta w każdym języku. Przykład działa na stronie testowej. Importy pominięto.

public class LoginPage extends PageObjectParameterized {

    @FindByParameterized(xpath = "//button[text()='{wec:btn.text}']")
    WebElement submit;

    @FindBy(id = "username")
    WebElement username;

    public LoginPage(SearchContext searchContext) {
        super(searchContext);
    }
}
@DataProvider(name = "languages")
Object[][] languages() {
    return new Object[][]{ {"pl", "Zaloguj"}, {"en", "Sign in"} };
}

@Test(dataProvider = "languages")
void loginButtonIsAvailable(String lang, String buttonText) {
    driver.get("https://maciejsocha.github.io/automation-demo.html");
    driver.findElement(By.id("lang-" + lang)).click();

    DefaultParameterProvider.properties.set(Map.of("btn.text", buttonText));
    LoginPage page = new LoginPage(driver);
    page.submit.click();
}

Parametry ustawiasz przed utworzeniem strony. Page Object czyta je w momencie inicjalizacji.
